# Changelog

## 1.0.0

Versão inicial pública e genérica.

### Incluído

- coleta baseada no histórico do Windows Update Agent;
- registro no Event Viewer;
- correlação de execução manual/automática quando possível;
- tentativa de identificação de usuário;
- identificação de Windows Update, Microsoft Update e WSUS;
- estado persistente para evitar duplicidade;
- Scheduled Task como SYSTEM;
- ACL restritiva;
- SHA256 de arquivos de runtime;
- health check;
- instalador e desinstalador;
- documentação de segurança e arquitetura.
